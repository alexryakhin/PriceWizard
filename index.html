FAQ

Questions

What do I need?

iOS or iPadOS 17 or later, or macOS 15 or later, and an App Store Connect API key with App Manager or Admin access. How to create one.

Is my API key safe?

It's stored only in your device's Keychain and used only to sign requests that go directly from your device to Apple. We never receive it. See the Privacy Policy.

Can I try it without an API key?

Yes. Tap Try Demo on the connect screen to explore with sample apps and products. Nothing is sent to App Store Connect in demo mode.

What counts as an "apply"?

Each time you send prices, an introductory offer or localization changes to App Store Connect. Retrying failed territories doesn't count again.

Will it overwrite scheduled price changes?

Only on the start date you choose: scheduled prices on that date are replaced (the review sheet tells you how many), territories already at the new price are skipped, and other dates are left alone.
