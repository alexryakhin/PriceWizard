Create an App Store Connect API key

  1. Open App Store Connect → Users and Access → Integrations → App Store Connect API.
  2. Create a Team Key with the App Manager or Admin role.
  3. Download the .p8 file. Apple lets you download it only once.
  4. Copy the Key ID and the Issuer ID from the same page.
  5. In Price Wizard, enter both IDs and choose the .p8 file. The key is saved in your Keychain.

Just looking? Tap Try Demo on the connect screen to explore with sample data.

Common issues

“Invalid API key” or the connection fails

Check the Key ID and Issuer ID, and that the .p8 file is complete (from -----BEGIN PRIVATE KEY----- to -----END PRIVATE KEY-----). Make sure the key hasn’t been revoked.

403 “Forbidden” errors

The key needs the App Manager or Admin role. Developer or Marketing keys can’t change prices, offers or product metadata.

“Must be on or after …” when applying subscription prices

App Store Connect only accepts price changes a couple of days ahead (Pacific Time). Price Wizard moves the start date to the earliest day Apple accepts; tap Retry Failed Territories. Subscriptions that were never approved apply right away instead.

Some territories failed

The rest still went through. Tap Retry Failed Territories; each failure shows Apple’s reason. Running the same apply again also finishes the job: territories that already match are skipped.

Prices didn’t change in some countries

Countries already at the target price are skipped, and a manual price you set stays until you reset it (swipe or right-click the row).

Introductory offers

Open a subscription, then ⋯ → Introductory Offers. Pick Free Trial, Pay as You Go or Pay Up Front, the territories, and optional dates. Creating an offer replaces any existing offer in those territories. Apple allows one introductory offer per territory at a time.

CSV and copying prices

  • Export writes Territory, Code, Currency, Current price, New price, New price (USD) and Change %.
  • Import needs a territory column (code like DEU or DE, or the country name) and a price column in local currency. Commas, semicolons or tabs all work, as do decimal commas.
  • Copy Prices From loads another product’s current prices, from any of your apps.
  • Imported and copied prices snap to the nearest valid App Store price and show up as manual prices you can review before applying.

Mac: MCP server for AI tools

Open About → MCP Server, turn it on and copy the config snippet for Cursor, Claude Code or VS Code. The server listens on 127.0.0.1 only and needs the token shown there. AI tools can prepare prices, offers and localizations; applying always needs your click in Price Wizard.

Purchases

To unlock on a new device, use Restore Purchases on the paywall (also in Settings on iPhone and iPad). Refunds are handled by Apple at reportaproblem.apple.com.

Requirements

  • iOS / iPadOS 17 or later, or macOS 15 or later
  • An App Store Connect API key with App Manager or Admin access
